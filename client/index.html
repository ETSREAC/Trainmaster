📡 ESP32 WIO (Wireless I/O) Rückmeldesystem

Empfängt Rückmeldesignale drahtlos von ESP32-Modulen über UDP-Datagramme (Rocrail WIO / RocNet-kompatibel) oder HTTP REST.

Standardport 8051 für Rocrail WIO-Firmware oder eigene ESP32-Skripte.
POST http://<TrainMaster-IP>:3001/api/wio/sensor
JSON: {"unit": 1, "pin": 3, "state": true}
